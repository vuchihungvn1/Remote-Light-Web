# Remote Light

- [Mở giao diện điện thoại](https://vuchihungvn1.github.io/Remote-Light-Web/)
- [Tải bộ cài Windows 64-bit](https://github.com/vuchihungvn1/Remote-Light-Web/releases/latest/download/RemoteLight-Setup.msi)

Mở Remote Light trên Windows, quét mã QR bằng điện thoại rồi xác nhận trên máy tính.

Repo này cung cấp web đã đóng gói và bộ cài. Actions kiểm tra các tệp web
trước khi đưa lên Pages và kiểm tra SHA-256 của bộ cài trong GitHub Releases.
